Tier 1 — Core Hooks go deep

1. useEffect & lifecycle + cleanup ⚠️ high priority
  • What: run side-effects, clean up on unmount.
  • Technical points: dependency array, cleanup function, EventSource lifecycle.
  • Learn from: useWalletStream.ts — real SSE. Common bug: forgetting to close the stream / duplicate connections.
  • Why it matters: the SSE reconnect/leak bug just fixed in commit 3b81d21 is exactly this class of bug.
2. useContext already used — reinforce
  • AuthContext.tsx, ToastContext.tsx.
  • Trade-off: Context re-renders every consumer when the value changes → why you shouldn't dump all global state into a single context.
3. useMemo / useCallback / useRef ⚠️
  • Learn from: balanceSeries.ts + Spark.tsx — chart math worth memoizing.
  • Why: avoid recomputing the balance series on every render. Trade-off: memoization isn't free — don't memoize everything.

Tier 2 — Routing react-router v7

  • In the project: App.tsx, split AdminApp vs consumer pages, LoginPage.tsx.
  • Learn: nested routes, <Outlet>, protected routes (tied to AuthContext), useNavigate, useParams.
  • Exercise: visiting /wallets/:id while logged out should redirect to /login.

Tier 3 — Server state: TanStack Query ⭐ core focus

CLAUDE.md mandates: "All server state goes through TanStack Query. No useEffect + fetch."

  • In the project: useWallets.ts, useLedger.ts, useEvents.ts.
  1. useQuery — queryKey, staleTime, caching (already used).
  2. useMutation + invalidateQueries — after top-up/transfer, refresh the balance.
  3. Optimistic updates — update the UI before the server responds (TransferForm.tsx).
  4. Query key factory — standardize keys so invalidation hits the right thing.

Why over useEffect+fetch: handles caching, dedupe, retry, loading/error for you. Trade-off: adds a layer of concepts (queryKey, staleTime) — get them wrong and you'll see "stale data".

Tier 4 — Forms & Validation ⚠️

  • In the project: TopUpForm.tsx, TransferForm.tsx, AddWalletModal.tsx.
  • roadmap.sh suggests: React Hook Form + Zod.
  • Why: money forms need client-side BigDecimal/currency validation (matching the backend money rules). Trade-off: adding Zod buys declarative, type-safe validation at the cost of another dependency.

Tier 5 — Patterns & Performance advanced

  • Custom hooks ✅ — you already have hooks/.
  • Composition vs prop drilling — look at the components/consumer/ tree.
  • React.memo, code-splitting lazy/Suspense — split AdminApp into its own bundle.
  • Error Boundaries — one error shouldn't crash the whole app.

Tier 6 — Testing gap

  • The frontend currently has no tests (only npm run build).
  • Learn: Vitest + React Testing Library → test TransferForm.tsx (render → type → submit → mock the mutation).
